# REDSkill 上传页字段对照

在生成提交资料前阅读本文件。它记录的是小红书创作服务平台当前可核验的 Red Skill 上传流程；页面随时可能更新，以用户账户的实时页面为准。

## 已观察到的上传流程

1. 上传源码。
2. 填写信息。
3. 提交后等待审核；审核通过的 Skill 会在管理页显示版本和“生效中”。

## 第一步：上传源码

| 官方页面项目 | 当前页面提示 | Forge 输出 |
| --- | --- | --- |
| 上传内容 | 含 `SKILL.md` 的文件夹或 ZIP | 独立候选目录与 `<internal-id>-redskill.zip` |
| 文件大小 | 单文件最大 10MB；总大小不超过 30MB | 审计中的大小检查 |
| 内容来源 | 原创 / 转载（二选一） | 来源建议与权利核对 |
| 安全规范 | 阅读并同意《Skill 发布安全规范》 | 风险审计和提交前清单 |

官方页面明确显示“上传源码 → 填写信息”的两步流程。只有成功上传并解析源码后，第二步的实时字段才会出现；不要在未进入第二步时把历史截图或第三方页面中的字段当成当前官方要求。

## Forge 应生成的填写建议

Forge 仍然生成以下建议，供 `SKILL.md` 元数据、第二步实时页面和后续版本管理使用：

- 展示名称建议；
- 稳定的英文内部 ID 建议，仅用于包名和作者管理，不声称它一定是页面字段；
- 简介建议；
- 语义化版本号建议；
- 来源类型、署名与授权建议；
- 权限、数据访问和安全边界建议。

把官方页面已确认的要求与 Forge 建议分开写。第二步实际出现哪些输入框，就按实时页面逐项复制；没有出现的项目保留在提交建议或审计文档中。
