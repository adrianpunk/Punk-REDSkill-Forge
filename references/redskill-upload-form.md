# REDSkill 上传页字段对照

在生成提交资料前阅读本文件。它记录的是当前可核验的上传表单字段；小红书随时可能更新页面，以用户账户的实时页面为准。

## 已观察到的上传流程

1. 上传源码 ZIP。
2. 填写信息：Skill 名称、Skill ID、简介、Skill 介绍。
3. 提交审核。

## 已观察到的必填字段

| 页面字段 | 当前页面提示/上限 | Forge 的对应输出 |
| --- | --- | --- |
| 上传源码 | ZIP | `<skill-id>-redskill.zip` |
| Skill 名称 | 必填；界面显示 `15` 字上限 | `skill_name` |
| Skill ID | 必填；提示“请输入唯一标识（英文、数字、连字符）”；界面显示 `128` 上限 | `skill_id` |
| 简介 | 必填；界面显示 `1000` 上限 | `intro` |
| Skill 介绍 | 必填；用于详情页/预览 | `skill_introduction` |

## 生成约束

- 名称写给用户看，默认生成不超过 15 个字符的中文候选名称；无法保证长度时显式标记为需要人工缩短。
- ID 写给系统看，默认生成小写英文、数字和连字符组成的稳定候选值；需在页面确认唯一性。
- 简介先说“用户能得到什么”，避免内部实现细节、平台背书或审核承诺。
- Skill 介绍应包含能力说明、用户如何使用、输入与输出、明确边界；它必须与 ZIP 中 `SKILL.md` 的实际能力一致。
- 未出现在表单中的权限、数据、第三方权利、安全边界等事项写进 `REDSKILL-AUDIT.md`，作为审核前核对材料，不伪装为表单字段。
